TwoDCraft - Windows app project (v1.2: LAN multiplayer)
1) Install Node.js LTS from https://nodejs.org (default settings).
2) Double-click start-dev.bat to test the game in a window.
3) Double-click build.bat to build TwoDCraft Setup.exe and a portable .exe (folder "dist").
Multiplayer: Esc menu -> "Open world for friends" (host) / "Connect by IP" (guest). Port 7777, up to 5 players.
Saves: Documents\TwoDCraft\saves\world.json
To update the game: replace index.html with the new game file (rename it to index.html) and run build.bat again.
Installer: on the last page there is a checkbox 'Create desktop shortcut' (your choice on every install).
Editor: in game press Esc -> 'Editor (TwoDCraft Studio)'. Your mod is saved to Documents\TwoDCraft\mods\mod.json
